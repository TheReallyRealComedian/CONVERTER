# 04 — Verbundene Zellen (rowspan/colspan)

**Was ist hier schwierig?** Zweistufiger Tabellenkopf mit echtem Spaltenverbund *und*
Zeilenverbund gleichzeitig: „Netto-RW (Unique User)" spannt drei Spalten, „Brutto-Reichweite
(Kontakte)" zwei, während „Fälle (ungew.)" über beide Kopfzeilen hinweg verschmilzt. In
reinem Markdown ist das nicht darstellbar — an dieser Datei entscheidet sich, ob der
Konverter für solche Fälle auf HTML-Tabellen ausweichen muss.

- Datei: `06_ranking_angebote_monat_if2010_I.pdf` — AGOF, Ranking Angebote/Monat
- 12 Seiten, DE, nativ; geometrisch verifiziert: 98 Zellen mit echtem Span auf S. 12
- Öffentlicher Branchenanhang → cloud-fähig

Bonus: Die Tabelle läuft zusätzlich über Seitengrenzen — ein Konverter, der #03 löst, aber
hier den Kopf verliert, hat nur das halbe Problem gelöst.
