# 02 — Regulatorische Guideline (Stellvertreter)

**Was ist hier schwierig?** Tief nummerierte Gliederung (1. / 2. / 2.1 / 2.2 …), die als
Überschriftenhierarchie und nicht als Fließtext erkannt werden muss, plus über viele Seiten
laufende Ergebnistabellen mit Kopfzeilenwiederholung.

- Datei: `berichtsband_if2010_II.pdf` — AGOF *internet facts 2010-II*, Berichtsband
- 57 Seiten, DE, nativ; `toc=60`, 25 erkannte Tabellen
- Öffentlich publizierter Branchenbericht → cloud-fähig

**⚠️ Das ist ein Ersatz, kein Volltreffer.** In der Nextcloud liegt **keine einzige** ICH-,
EMA- oder FDA-Guideline (vollständige Suche über alle 3.645 PDFs, siehe `../LUECKEN.md`).
Der AGOF-Bericht bildet Gliederungstiefe und Tabellenlast ab, aber **nicht** den
Fußnotenapparat und nicht die regulatorische Sprache. Für den echten Test bitte eine
Guideline nachladen — Vorschlag in `../LUECKEN.md`.
